# 🌍 CAR-HAUSE Portal

Bu layihə müxtəlif ölkələrin **avtomobil** və **daşınmaz əmlak** satış saytlarını bir platformada toplayır. 
İstifadəçilər rahatlıqla ölkə seçərək müvafiq avtomobil və ev alqı-satqısı saytlarına keçid edə bilirlər.

## 🚀 Xüsusiyyətlər
- Ölkələr üzrə bölünmüş kartlar (Azərbaycan, Almaniya, İngiltərə, ABŞ, Türkiyə, Rusiya, Gürcüstan, İtaliya).
- Hər kartda bayraq şəkli və müvafiq linklər.
- Sadə, modern və mobil uyumlu dizayn.
- Dünyadakı istifadəçilər üçün rahat naviqasiya.
